What is NumPy? Why is it faster than Python lists?

NumPy Foundations 7 min read Difficulty: Beginner 1 of 40
Definition

NumPy (Numerical Python) is the core library for numerical computing in Python. Its central object is the ndarray: an n-dimensional array of elements of one data type, stored in a contiguous block of memory.

It is fast because operations are vectorised: one call runs a compiled C loop over the whole array, with no per-element Python type checks, using CPU caches and SIMD instructions. A list instead holds pointers to separate Python objects.

Analogy
A list is a notice board with sticky notes pointing to files kept in different cupboards; to add marks you visit every cupboard. A NumPy array is one printed sheet with all marks in a row; the calculator runs down the sheet in one sweep.
How It Works — Step by Step
Step 1 / 5
  1. 1A Python list stores pointers to separate Python objects. Every number carries its own type information and reference count.
  2. 2A NumPy ndarray stores raw values of one dtype in one contiguous block of memory.
  3. 3Operations such as a * 2 run one compiled loop over that block: no per-element type checks, good use of CPU cache and vector (SIMD) instructions.
  4. 4Result: much faster arithmetic and much less memory than the equivalent list code.
  5. 5Almost the whole Python data stack is built on top of ndarrays.
Real-World Scenario
Under every data tool

pandas columns, scikit-learn feature matrices, images in OpenCV, tensors converted from PyTorch: all are (or convert to) NumPy arrays. Scoring 1 million answer sheets, normalising features or computing distances between student profiles are one-line NumPy expressions.

Cross Questions
Is NumPy always faster than a list?
For numeric work on many elements, yes. For a handful of elements, or for appending items one by one, lists are fine or faster (arrays have a fixed size; appending copies).
Why must all elements have the same type?
So each element has a fixed size and position: element i is at start + i × itemsize, enabling direct addressing and compiled loops.
What is SIMD?
Single Instruction, Multiple Data: CPU instructions that process several numbers at once; NumPy's inner loops use them where available.

What are the main attributes of an ndarray (shape, ndim, dtype, strides)? What is an axis?

NumPy Foundations 7 min read Difficulty: Beginner 2 of 40
Definition

An ndarray is a memory buffer plus metadata: shape (size along each dimension), ndim (number of dimensions), size (total elements), dtype (element type), itemsize (bytes per element), nbytes, and strides (bytes to step along each dimension).

An axis is a dimension. In a 2-D array, axis 0 runs down the rows and axis 1 across the columns. sum(axis=0) collapses the rows, giving one value per column.

shape ndim dtype strides axis
Analogy
A theatre: shape is "20 rows × 30 seats", dtype is "every seat is the same size", and strides are the instructions "to reach the next seat walk 1 step, to reach the next row walk 30 steps".
How It Works — Step by Step
Step 1 / 5
  1. 1A 2-D array of marks: 2 rows (students) and 3 columns (subjects).
  2. 2Attributes describe it: shape, number of dimensions, element count, dtype and bytes per element.
  3. 3In memory it is a flat block of 6 values stored row after row (C order).
  4. 4Strides say how many bytes to jump to move one step along each axis: 24 bytes to the next row, 8 to the next column.
  5. 5Because an array is "buffer + shape + strides", many operations just create a new description of the same buffer. Axis 0 runs down the rows, axis 1 across the columns.
Real-World Scenario
Thinking in axes

A marks matrix of 120 students × 6 subjects has shape (120, 6). marks.mean(axis=0) gives the 6 subject averages; marks.mean(axis=1) gives the 120 student averages. A batch of 64 colour images for a CNN has shape (64, 224, 224, 3).

What is the shape of a 1-D array of 5 elements?
(5,): a one-element tuple. (5, 1) is a 2-D column and (1, 5) a 2-D row.
Why are strides useful to know?

How do you create arrays? What is the difference between arange and linspace?

NumPy Foundations 7 min read Difficulty: Beginner 3 of 40
Definition

From data: np.array(list), np.asarray (no copy if already an array). Filled: zeros, ones, full, empty, eye/identity, zeros_like. Ranges: arange(start, stop, step) and linspace(start, stop, num). Random: np.random.default_rng(seed) then integers, random, normal, choice.

arange takes a step and excludes the stop value; with float steps the count can be surprising due to rounding. linspace takes the number of points and includes the stop value by default.

np.array arange linspace zeros default_rng
Analogy
arange is "walk from the gate in 3-metre steps and stop before the wall". linspace is "place exactly 5 poles from the gate to the wall, evenly spaced": you always get 5 poles and one stands at the wall.
How It Works — Step by Step
Step 1 / 5
  1. 1From existing data: np.array on a list (or nested lists for 2-D).
  2. 2Pre-filled: zeros, ones (float64 by default), useful as starting buffers.
  3. 3arange is like Python range: you give the step, and the stop value is excluded.
  4. 4linspace gives a number of points, evenly spaced, and includes the stop value. Safer than arange with float steps.
  5. 5Others: full, eye (identity), empty (uninitialised, fast) and random arrays from a Generator.
Real-World Scenario
Typical uses

np.zeros((n_students, n_subjects)) to fill marks in a loop over files; linspace for x-values of a plot or thresholds to test (0.1 to 0.9 in 9 steps); default_rng(42) for reproducible sample data and train/test splits.

  1. Have the data?
    np.array(data, dtype=...).

Cross Questions
Why can np.arange(1, 1.3, 0.1) have 4 elements?
Floating-point rounding: 0.1 cannot be stored exactly, so 1 + 3×0.1 can be slightly below 1.3 and is included. Use linspace for floats.
np.array vs np.asarray?
np.array copies by default; asarray returns the input unchanged if it is already an array of the right dtype.
Why prefer default_rng over np.random.seed?
Generators are independent objects (no global state), use a better algorithm (PCG64) and are the recommended API since NumPy 1.17.

What are NumPy dtypes? What happens on overflow and type conversion?

NumPy Foundations 8 min read Difficulty: Beginner 4 of 40
Definition

A dtype fixes the type and size of every element: int8/16/32/64, uint8…, float16/32/64, complex, bool, datetime64, fixed-width strings <U10, object, and in NumPy 2 the variable-length StringDType.

Consequences: integer overflow wraps around silently in arrays; mixed inputs are upcast to a common type; astype converts (copying) and float → int truncates. NumPy 2 (NEP 50) changed scalar promotion: the array's dtype wins over Python numbers, and out-of-range Python ints raise OverflowError.

dtype astype overflow type promotion NEP 50
Analogy
Dtypes are box sizes. A small box (int8) is cheap but holds only up to 127; force 200 in and the counter rolls over like an old car odometer going from 99999 to 00000.
How It Works — Step by Step
Step 1 / 5
  1. 1Every array has one dtype with a fixed size, which fixes its range or precision.
  2. 2Integer arithmetic that exceeds the range wraps around: 100 + 100 in int8 gives -56. Arrays do this without any warning.
  3. 3Mixed input is converted to one common dtype: here everything becomes a string.
  4. 4astype converts (and copies); converting floats to ints truncates toward zero.
  5. 5NumPy 2 changed promotion rules (NEP 50): the array/scalar dtype wins, and a Python int that does not fit raises an error.
Real-World Scenario
Image brightness bug

Images are uint8 (0–255). Adding 50 to brighten a photo made white areas dark: 230 + 50 wrapped to 24. The fix: convert to a larger type, add, clip to 0–255, convert back. The same applies to counters stored in small integer types.

Steps to Avoid dtype Bugs
  1. Choose deliberately
    float64/int64 by default; smaller types to save memory when the range allows.
  2. Check limits
    np.iinfo(dtype) and np.finfo(dtype).
  3. Upcast before risky maths
    Convert uint8 images or int16 counters to a bigger type first.

Cross Questions
Why does an int array with None become object dtype?
Integers have no missing-value representation; NumPy falls back to object. Use float with np.nan, or pandas nullable types.
What changed in NumPy 2 promotion?
NEP 50: Python scalars are "weak": float32 array * 3.0 stays float32, and np.int8(100) + 200 raises OverflowError instead of quietly becoming int16/int64.
What is the difference between <U5 and StringDType?
<U5 is fixed-width (5 characters, longer strings are cut off); StringDType (NumPy 2) stores variable-length strings.

How do reshape, ravel, flatten and transpose work? What does -1 mean in reshape?

NumPy Foundations 7 min read Difficulty: Beginner 5 of 40
Definition

reshape(new_shape) gives the same elements in a new shape; the total size must match. One dimension may be -1, which NumPy computes. It returns a view when possible.

ravel() flattens to 1-D, a view when possible; flatten() always returns a copy. .T / transpose() reverses (or permutes) axes by changing strides. np.newaxis/expand_dims add an axis of length 1; squeeze removes them.

reshape ravel flatten transpose -1
Analogy
An egg tray of 12 can be arranged as 2×6 or 3×4 or one line of 12: the eggs are the same, only the arrangement changes. "-1" means "you figure out the other side": 3 rows → 4 per row.
How It Works — Step by Step
Step 1 / 5
  1. 1Six values in a 1-D array.
  2. 2reshape(2, 3) reads the same values row by row into 2 rows of 3.
  3. 3One dimension can be -1: NumPy computes it from the total size.
  4. 4.T transposes: rows become columns. It only swaps the strides.
  5. 5ravel flattens (a view if possible), flatten always copies; the total size must match or reshape fails.
Real-World Scenario
Machine-learning shapes

scikit-learn expects a 2-D feature matrix: a single feature column x of shape (100,) must become (100, 1) with x.reshape(-1, 1). A 28×28 image is flattened to 784 values for a dense layer with img.reshape(-1).

Steps to Reshape Safely
  1. Count elements
    The product of the new shape must equal a.size.
  2. Use -1 once
    For the dimension you do not want to compute yourself.
  3. Single feature for ML
    x.reshape(-1, 1).

Cross Questions
Does reshape copy data?
Not if the data can be described with new strides (usually for C-contiguous arrays); otherwise (e.g. reshaping a transposed array) it copies.
What is the difference between reshape and resize?
reshape returns a new view/array and requires the same size; resize changes the array in place and can pad or truncate.
What is order="F"?
Read/write elements column by column (Fortran order) instead of row by row (C order).

How does indexing and slicing work on multi-dimensional arrays?

Indexing & Selection 7 min read Difficulty: Basic 6 of 40
Definition

NumPy indexes each axis inside one pair of brackets: a[row, col]. Each position can be an integer (picks one, removes that axis), a slice start:stop:step (keeps the axis), or : (everything). Negative indexes count from the end; ... (Ellipsis) means "all remaining axes".

Basic slicing returns a view (no copy).

ExpressionResult
a[1, 2]single element
a[1] or a[1, :]row 1 (1-D)
a[:, 2]column 2 (1-D)
a[:, 2:3]column 2 as 2-D (n, 1)
a[:2, 1:3]block
a[::-1]rows reversed
a[..., 0]first element of the last axis
indexing slicing view Ellipsis
Analogy
A seating chart: "row 2, seat 3" is one person; "everyone in seat 3" is a column; "rows 1–2, seats 3–4" is a block. One instruction, all axes at once.
How It Works — Step by Step
Step 1 / 5
  1. 1One comma-separated index per axis: row 1, column 2 gives one element.
  2. 2A colon means "all" on that axis: every row of column 1 → a 1-D array.
  3. 3Slices on both axes cut out a block: first two rows, columns 2 to the end.
  4. 4Negative indexes count from the end; steps skip or reverse.
  5. 5Chained a[1][2] creates an intermediate array first; a[1, 2] is the NumPy way.
Real-World Scenario
Marks matrix

With students as rows and subjects as columns: marks[:, 2] is one subject for everyone, marks[5] one student's results, marks[-10:] the last ten students. For images (height, width, channels), img[:, :, 0] is the red channel and img[100:200, 50:150] a crop.

  1. Write one index per axis
    a[rows, cols], separated by commas.
  2. Use slices to keep dimensions

a[1][2] vs a[1, 2]?
Same value, but a[1][2] first builds a[1] then indexes it; a[1, 2] is one operation, and a[:, 2] cannot be written with chained brackets.
Why does a[:, 2] lose a dimension?

What does a[[1]] return?

What is boolean masking? How do you filter and update values with conditions?

Indexing & Selection 7 min read Difficulty: Basic 7 of 40
Definition

A comparison on an array (marks >= 60) returns a boolean array of the same shape. Indexing with it (marks[mask]) returns the selected elements as a new 1-D array; assigning through it (marks[mask] = 0) modifies the original in place.

Combine conditions with &, |, ~ and parentheses. Because True = 1, mask.sum() counts and mask.mean() gives the fraction; np.any/np.all test conditions, with an axis if needed.

boolean mask filtering np.any np.all count_nonzero
Analogy
A stencil laid over the marks sheet with holes only where the condition is true: you read (or paint) only through the holes.
How It Works — Step by Step
Step 1 / 5
  1. 1An array of marks.
  2. 2A comparison is applied element-wise and returns a boolean array of the same shape.
  3. 3Indexing with the boolean array keeps only the True positions: a new 1-D array (a copy).
  4. 4Assigning through a mask changes the original elements in place: every fail mark set to 0.
  5. 5Combine conditions with &, | and ~; True counts as 1, so sum and mean give counts and fractions.

Result processing

  1. Build the mask
    One comparison per condition, in parentheses.

What is fancy indexing? How is it different from slicing?

Indexing & Selection 7 min read Difficulty: Basic 8 of 40
Definition

Fancy (integer-array) indexing selects elements using arrays or lists of positions: a[[2, 0, 5]]. Positions can repeat and be in any order. With several index arrays, they are paired element-wise: m[[0, 2], [2, 0]] → elements (0,2) and (2,0). np.ix_ builds a cross product to select a sub-matrix.

Unlike slicing, fancy indexing always returns a copy, and the result shape follows the shape of the index arrays.

fancy indexing np.ix_ argsort take copy
Analogy
Slicing is "seats 3 to 7". Fancy indexing is a guest list: "seat 12, then seat 3, then seat 12 again", in exactly that order.
How It Works — Step by Step
Step 1 / 5
  1. 1A 1-D array with positions 0–5.
  2. 2Indexing with a list of positions picks those elements in that order.
  3. 3On 2-D arrays, two index arrays are paired element by element: (0, 2) and (2, 0).
  4. 4To take a rectangular sub-matrix from chosen rows and columns, use np.ix_.
  5. 5Unlike basic slices, fancy indexing copies data. It combines well with argsort/argmax, which return positions.

Definition

What is C order vs Fortran order? What are contiguous arrays and why do they matter?

Definition

A multi-dimensional array is stored as a flat buffer. C order (row-major, NumPy default) stores rows one after another: the last index varies fastest. Fortran order (column-major) stores columns one after another.

An array is contiguous when its elements fill the buffer without gaps in that order. Slices with steps and transposes produce non-contiguous views. Operations that read memory sequentially are faster (CPU cache); some C/Fortran libraries require a specific layout, which np.ascontiguousarray/np.asfortranarray provide.

  2. 2C order stores row after row: the last index changes fastest.
  3. 3Fortran order stores column after column: the first index changes fastest.
  4. 4Operations that walk memory sequentially use the CPU cache well, so layout can affect speed for big arrays.
  5. 5Flags tell you the layout; some libraries require contiguous input, which ascontiguousarray provides.

Why exactly is NumPy fast? Where does the speed-up come from?

Performance & Numerics 8 min read Difficulty: Advanced 26 of 40
Definition

Four reasons: (1) no per-element interpreter overhead: type checks and dispatch happen once per operation, then a compiled loop runs; (2) homogeneous, contiguous memory: raw values, good CPU-cache use and prefetching; (3) SIMD instructions process several values per instruction; (4) optimised libraries: linear algebra calls BLAS/LAPACK (OpenBLAS, MKL), often multi-threaded.

Limits: each operation still makes one pass and usually one temporary array; small arrays are dominated by call overhead; Python-level loops over arrays (or object dtype) lose all the benefits.

performance SIMD BLAS cache overhead
Analogy
Paying 10,000 cheques at a bank: one clerk verifying each cheque's signature, account and amount one by one (Python), versus a bulk transfer file checked once and processed by the bank's system in a single batch (NumPy).
How It Works — Step by Step
Step 1 / 5
  1. 1A Python loop pays interpreter overhead for every element: fetching objects, checking types, dispatching, allocating results.
  2. 2NumPy does the checks once for the whole array.
  3. 3Then a compiled loop processes raw values, often several per CPU instruction (SIMD).
  4. 4The speed-up comes from removing per-element overhead, not from faster arithmetic.
  5. 5Contiguous memory helps caching; linear algebra calls optimised BLAS libraries that can use several cores.
Real-World Scenario
Where it shows

Computing z-scores for 10 million readings: a list loop takes seconds, NumPy tens of milliseconds. A 2000 × 2000 matrix product runs in a fraction of a second through BLAS. But a loop that calls NumPy on single elements is even slower than plain Python, because of call overhead.

How do you reduce memory use with NumPy (dtypes, in-place operations, out=)?

Definition

Memory = number of elements × itemsize, plus temporaries. Reduce it by: choosing smaller dtypes (float32, int32, uint8, bool), using views instead of copies, in-place operators (+=, *=) and out= to avoid temporaries, deleting large intermediates (del), and memory-mapping data that does not fit in RAM.

In-place operations must keep the dtype (an int array cannot hold float results in place) and they change the original data and its views.

When can broadcasting cause memory problems? What is np.einsum?

Performance & Numerics 8 min read Difficulty: Advanced 28 of 40
Definition

Broadcasting itself does not copy, but the result has the full broadcast shape. Expressions like X[:, None, :] - X[None, :, :] create an (n, n, d) array, which grows quadratically: easy to exhaust memory.

np.einsum(subscripts, *arrays) describes products and sums with index notation (Einstein summation), e.g. "ij,jk->ik" (matmul), "ij,ij->i" (row-wise dot), "ii->" (trace), "bij,bjk->bik" (batch matmul). It avoids building large intermediates; optimize=True chooses a good contraction order.

broadcasting einsum memory pairwise distance
Analogy
To find the distance between every pair of 20,000 cities, you do not need to write out every coordinate difference on a sheet; a clever formula from each city's own numbers and one multiplication table (X @ X.T) gives the same distances on a much smaller sheet.
How It Works — Step by Step
Step 1 / 4
  1. 1A naive pairwise-difference broadcast creates an n × n × d array: impossible for large n.
  2. 2Rewriting the maths with a matrix product needs only the n × n result.
  3. 3einsum expresses sums over indices (dot products, traces, batch matmul) without building big intermediates.
  4. 4Before broadcasting, multiply out the result shape and itemsize to estimate memory.
Real-World Scenario

Finding similar students from 50 performance features: naive broadcasting for 20,000 students would need ~160 GB. Using ‖a−b‖² = ‖a‖² + ‖b‖² − 2a·b with one matrix product needs only the 20,000 × 20,000 result, or process in row blocks.

What floating-point and numeric pitfalls should you know in NumPy?

Performance & Numerics 8 min read Difficulty: Advanced 30 of 40
Definition

Floats are binary approximations: 0.1 + 0.2 ≠ 0.3 exactly, so compare with np.isclose/np.allclose (relative and absolute tolerances). float32 has ~7 significant digits, float64 ~15–16. Large + small numbers lose the small one; subtracting nearly equal numbers loses precision (cancellation). Summation order changes results slightly (NumPy uses pairwise summation).

Integers overflow and wrap silently in arrays; // and % floor toward −∞ for negatives; NaN propagates and never equals itself. For money use integer paise or Python's Decimal.

floating point isclose allclose precision overflow
Analogy
Measuring with a ruler marked in millimetres: you cannot measure exactly one-third of a centimetre, and if you add a hair's width to the length of a building, the ruler will not notice. Floats are such rulers, in binary.
How It Works — Step by Step

  2. 2Compare with a tolerance: np.isclose element-wise, np.allclose for whole arrays.
  3. 3float32 keeps about 7 significant digits; adding a small number to a large one can do nothing.
  4. 4Summation order matters; NumPy uses pairwise summation to reduce error, so results can differ slightly from a Python loop.
  5. 5Integer overflow and floor division rules are other sources of surprise; use integers (paise) or Decimal for money.

Definition

Step 1 / 4
  1. 1A typical O(n²) Python double loop: for each student, count classmates with a higher total.
  2. 2Broadcasting a row against a column builds the full comparison matrix; summing each row gives the counts.
  3. 3General recipe: each loop becomes an axis, each if becomes a mask, each counter or total becomes a reduction.
  4. 4Broadcast solutions trade memory for speed (n × n booleans here); always compare against the loop on small data.
Real-World Scenario

Example: Double Loop → Broadcasting → Sort-based Rank
Python (NumPy)
import time
rng = np.random.default_rng(3)
total = rng.integers(150, 300, 2000)

def loop_version(t):
    n = len(t); rank = np.empty(n, int); near = np.empty(n, int)
    for i in range(n):
        higher = close = 0
        for j in range(n):
            if t[j] > t[i]: higher += 1
            if j != i and abs(t[j] - t[i]) <= 5: close += 1
        rank[i], near[i] = higher + 1, close
    return rank, near

def vector_version(t):
    diff = t[None, :] - t[:, None]                 # (n, n): t[j] - t[i]
    rank = (diff > 0).sum(axis=1) + 1
    near = (np.abs(diff) <= 5).sum(axis=1) - 1     # minus self
    return rank, near

s = time.perf_counter(); r1, n1 = loop_version(total[:300]); t_loop = time.perf_counter() - s
s = time.perf_counter(); r2, n2 = vector_version(total[:300]); t_vec = time.perf_counter() - s
print('identical:', (r1 == r2).all() and (n1 == n2).all())
print(f'300 students -> loop {t_loop:.3f} s, vectorised {t_vec * 1000:.2f} ms')

r, n = vector_version(total)
sorted_t = np.sort(total)
rank_sort = len(total) - np.searchsorted(sorted_t, total, side='right') + 1   # O(n log n)
print('2000 students, ranks agree:', (r == rank_sort).all(), '| top rank count:', (r == 1).sum())

Steps to Vectorise an Algorithm
  1. Write the loop first
    Small, obviously correct; keep it for testing.
  2. Map loops to axes
    i → rows, j → columns via [:, None] and [None, :].
  3. Map conditions and counters
    if → mask; counter → sum along the axis.
  4. Check memory
    n × n is fine for thousands, not for millions; then find an O(n log n) idea (sort/searchsorted).
  5. Compare outputs
    assert (loop == vectorised).all() on random inputs.

Definition

Cosine similarity between vectors a and b is a·b / (‖a‖‖b‖): 1 for the same direction, 0 for orthogonal. For a matrix X (rows = items), normalise rows (U = X / norm(X, axis=1, keepdims=True)) and compute S = U @ U.T for all pairs at once. It compares the pattern, not the level; centring each row first gives Pearson correlation, which is often more meaningful for marks.

cosine similarity normalisation recommendation correlation nearest neighbours
Analogy
Two students pointing in the same direction are similar even if one walked further: cosine measures the angle, not the distance. If distance matters too, use Euclidean distance; if you care about ups and downs relative to each student's own average, use correlation.
How It Works — Step by Step
Step 1 / 5
  1. 1Each student is a vector of marks.
  2. 2Divide each row by its length so every vector has length 1.
  3. 3One matrix product gives every pairwise cosine similarity.
  4. 4Students 0 and 2 score 1.00 although their marks are very different: cosine compares the pattern, not the level. Centring first measures correlation instead.
  5. 5Sorting a row of S gives the most similar students (excluding the student itself).
Real-World Scenario
Peer-study groups

Students are represented by their scores in 12 modules. Correlation-based similarity groups students with similar strengths and weaknesses for peer study; the same technique (on ratings or embeddings) drives course and content recommendations.

Example: Cosine vs Correlation and Nearest Neighbour
Python (NumPy)
names = np.array(['Anuj', 'Vineeta', 'Rohan', 'Meera'])
X = np.array([[82, 61, 70, 55],
              [91, 88, 79, 95],
              [41, 30, 35, 28],         # same pattern as Anuj, much lower level
              [60, 85, 58, 90]], dtype=float)

U = X / np.linalg.norm(X, axis=1, keepdims=True)
S = U @ U.T
print(S.round(3))

C = X - X.mean(axis=1, keepdims=True)                     # centre each student
Uc = C / np.linalg.norm(C, axis=1, keepdims=True)
R = Uc @ Uc.T                                             # = Pearson correlation
print(R.round(2))
print(np.allclose(R, np.corrcoef(X)))

for i, name in enumerate(names):
    best = [j for j in np.argsort(-R[i]) if j != i][0]
    print(f'{name:8} most similar pattern: {names[best]} ({R[i, best]:.2f})')

    One row per student.
  2. Decide what "similar" means

Cross Questions
Why is Anuj–Rohan cosine almost 1?
Their mark vectors point in nearly the same direction (Rohan ≈ half of Anuj in every subject); cosine ignores magnitude.
How does this scale to millions of items?
n × n is too big; use approximate nearest-neighbour libraries (FAISS, Annoy) or block-wise computation with top-k.
Cosine distance?
1 − cosine similarity; used by clustering and nearest-neighbour algorithms.

Definition

Monte Carlo simulation estimates probabilities by generating many random trials and counting outcomes; with NumPy, trials are rows of an array, so millions run in milliseconds. Bootstrap estimates the uncertainty of a statistic by resampling the observed data with replacement many times and looking at the spread (percentiles) of the statistic.

Monte Carlo bootstrap simulation confidence interval random
Analogy
Instead of working out the odds of a card game on paper, you play it a million times very quickly and count how often you win. Bootstrap is re-drawing your class from itself many times to see how much the average could wobble.
How It Works — Step by Step
Step 1 / 5
  1. 1Each row is one simulated exam of 20 four-option questions answered by pure guessing.
  2. 2Summing each row gives the number of correct answers per attempt.
  3. 3The fraction of attempts reaching the pass mark estimates the probability.
  4. 4Bootstrap: resample observed data many times to estimate the uncertainty of a statistic such as the mean.
  5. 5Because everything is vectorised, many trials run quickly; check against an exact result where possible.
Real-World Scenario
Exam design and reporting

Is a pass mark of 8/20 in a 4-option MCQ test safe against pure guessing? Simulation (checked against the binomial formula) answers it. When reporting a batch average to management, a bootstrap 95 % interval shows how precise that average is for a batch of 40 students.

Example: Guessing Probability (Checked Exactly) and a Bootstrap Interval
Python (NumPy)
from math import comb
rng = np.random.default_rng(99)
trials, q, p = 200_000, 20, 0.25
correct = (rng.random((trials, q)) < p).sum(axis=1)          # each row = one guessed exam
print('simulated P(score >= 8):', (correct >= 8).mean().round(4))
exact = sum(comb(q, k) * p**k * (1 - p)**(q - k) for k in range(8, q + 1))
print('exact binomial         :', round(exact, 4))
print('most likely score      :', np.bincount(correct).argmax())

marks = rng.normal(68, 12, 40).round()                       # one batch of 40 students
boots = rng.choice(marks, size=(10_000, marks.size), replace=True).mean(axis=1)
lo, hi = np.percentile(boots, [2.5, 97.5])
print(f'batch mean {marks.mean():.1f}, bootstrap 95% CI [{lo:.1f}, {hi:.1f}]')
se = marks.std(ddof=1) / np.sqrt(marks.size)
print(f'normal-theory CI      [{marks.mean() - 1.96 * se:.1f}, {marks.mean() + 1.96 * se:.1f}]')

Cross Questions
How accurate is a Monte Carlo estimate?
Its standard error is about sqrt(p(1−p)/trials): 200,000 trials give roughly ±0.001 for p ≈ 0.1.
When is bootstrap useful?
For statistics without simple formulas (median, percentiles, ratios) or when distribution assumptions are doubtful.
Why fix the seed?
So the exact numbers in a report can be reproduced; the conclusions should not depend on the seed.
